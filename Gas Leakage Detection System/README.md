# Gas Leakage Detection System
## Objective
### The purpose of this project is to design a system that is capable of monitoring multiple sections of a building and giving information about the gas levels, in case of a leakage, in every monitored compartment. The information will be used to control a safety measurements and emergency subsystem.
## Implementation steps
* Design an electrical circuit to monitor gas levels in multiple areas 
* Take information about gas levels from every area
* Implement an emergency and a safety measures subsystem
* Procces the information about gas levels to control the emergency and safety measures subsystem
* Analyse and test the behaviour with different values 
## Emergency subsystem
### The aim of the emergency subsystem is to give information to an user about the detection of poisonous gasses and the areas where the gas was detected. 
### This subsystem consists of notifying methods such as GSM messages and display on the user interface about which area is affected, as well as the activation of an alarm in the case of detection.
## Safety measures subsystem
### This system is capable of controlling the different monitored areas. 
### The components of this subsystem are:
* A ventilation system
* A centralised on/off system for the gas distribution system.
### The ventilation system will be activated only in the area where a detection occurred, thus improoving power economy
### For improoved safetiness, the centralised on/off system will be activated no matter which area is affected.
